Notebook changes:
- PEP 723 dependencies include pinned marimo; OpenMM CUDA 12 works with the host's CUDA-13-capable NVIDIA driver. Explicit Auto/CUDA/CPU controls; CPU thread selector defaults to 4. An explicitly requested CUDA platform never silently falls back.
- Defaults: 2 nm sphere, 900 K, 20 ps stability, 10 K/ps cycle. No external widget or dataset downloads. The Mishin file and bonus datasets are supplied in the ZIP.
- Each cycle saves 2430 energy rows and 27 snapshots at 100 K spacing, independent of rate. 200 K gives 15 frames; 50 K gives 51. Fixed-T run saves energy rows only. The initial structure is saved separately.
- Analysis reads the neighbouring MD runs directory, accepts uploads, and uses ASE plot_atoms for atomic views through matplotlib. Actual interior-atom counts guard the g(r) calculation; tiny particles display a message rather than dividing by zero. Single-frame files use a disabled slider.
- Bonus writes cu_fitted_eam.npz locally and provides a tested browser download. The integration remains a student task; the completed integration used for validation stays private.
