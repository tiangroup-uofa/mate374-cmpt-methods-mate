# Figures and demos glossary

A single index of every figure and interactive demo in the course site and the
source that produces it. Use it to find which script or notebook to edit when a
figure or demo needs to change, and to confirm nothing renders from an untracked
source.

## Regenerating figures

All scripted figures are rebuilt by one entry point, which the `full` Quarto
profile runs before rendering pages:

```bash
uv run --locked python scripts/render_figures.py
```

That script runs each generator in [`scripts/render_figures.py`](scripts/render_figures.py)'s
explicit list. **When you add a new figure generator, add it to that list** or a
full/CI build will not regenerate its output. Daily `quarto preview` /
`quarto render --to html` builds reuse the committed images and do not run the
generators.

Every generator saves at `dpi=300` (see the figure-generation policy in
[`AGENTS.md`](AGENTS.md)).

## Non-figure scripts

For completeness, these scripts in `scripts/` do not produce figures:

- [`render_figures.py`](scripts/render_figures.py) — runs every figure generator (above).
- [`render_answer_pdfs.py`](scripts/render_answer_pdfs.py) — renders and stages assignment answer PDFs (`full` profile).
- [`generate_llms_txt.py`](scripts/generate_llms_txt.py) — post-render hook that writes `llms.txt`.
- [`marimo_iframe_url.py`](scripts/marimo_iframe_url.py) — helper for the marimo-iframe Lua filter.
- [`export_l08_l09.py`](scripts/export_l08_l09.py) — focused WASM exporter kept for targeted checks; not a default build hook.
