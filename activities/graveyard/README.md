# Marimo notebook graveyard

These notebooks are retained for possible recovery, but are not part of the current course pages. `_marimo_export.py` exports only notebooks referenced by current Quarto pages or by an explicit `wasm-local/*.html` link; it does not scan this directory.

To restore one, move it back to `activities/` (or its original assignment path), add it to a current page, and render the site.
