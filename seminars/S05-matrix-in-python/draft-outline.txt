3) matrix inversion, just linalg.inv

4) condition number of matrix

use linalg.cond, this will give a scalar value for the condition number, which we introduced in class

if cond ~ 1 --> solution is stable
cond >> 1 --> solution very sensitive to either change of A or change of b

5) universal solve Ax=b

just call linalg.solve(A, b) in most cases!
